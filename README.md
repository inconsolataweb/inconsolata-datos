# Especiales de inconsolata»

Rama solo con las imágenes y páginas de los especiales a pantalla completa (/america250, /eps50…).
Vive aparte de `main` porque jsDelivr no sirve repositorios de más de 50 MB:
cada rama cuenta por separado.

Se sirven desde `https://cdn.jsdelivr.net/gh/inconsolataweb/inconsolata-datos@especiales/<especial>/`.
Las plantillas están en `main`, en `fuente/<especial>/tpl.html`: al cambiar una, se copia aquí como `<especial>/index.html`.
